# Terminal Chat (client-side)

Open [index.html](index.html) in a browser to run the simple terminal-style interactive chat. Everything runs client-side — no server needed.

Usage:

- Type `ready` and press Enter to receive a challenge.
- Click `Accept` to accept and return to start.
- Click `Decline` to decline, see a message, and return to start.
